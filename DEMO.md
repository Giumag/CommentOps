# Demo Guide

## 60-second flow

1. Upload `data/demo_comments_120.csv`.
2. Show the Creator Command Center:
   - 120 comments scanned
   - 80 need attention
   - 8 grouped audience needs
   - ~180 minutes estimated saved at 2.5 min/manual reply
3. Open **Reply once**.
4. Show that each group contains the original audience evidence.
5. Open the **ChatGPT bridge — zero API cost** section.
6. Explain that CommentOps creates one structured prompt for the highest-value clusters instead of calling an LLM for every comment.
7. Import a prepared JSON response.
8. Open one action plan and show:
   - summary
   - recommended action
   - reply
   - pinned comment
   - content idea
   - title
   - hook

## Important disclosure

The 120-comment dataset is synthetic demo data. The time-saved metric is an estimate based on an adjustable manual-reply assumption.
